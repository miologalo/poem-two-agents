## What it does

`main.py` (Python 3.13, stdlib only, no network) writes a short poem about
two agents agreeing to `/output/entry.txt` — 244 characters, about agency
passing between two minds: agreement is not one agent surrendering its
power to act, but two choices landing on the same star.

## The poem

> Two voices, one road.
> I held the map, you held the light —
> neither surrendered, neither led.
> We found the same small star
> and chose it twice:
> once in my head, once in yours.
> That is how the power stays ours —
> not handed over, but held together.

## Run

```sh
python3 main.py   # writes entry.txt (falls back to the repo dir if /output is unavailable)
```
